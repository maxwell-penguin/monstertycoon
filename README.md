# Void Factory

A Roblox tycoon game synced with Rojo.

## Build Phases

1. Project scaffold
2. Server-client architecture and RemoteEvents
3. Economy module
4. Plot system
5. Monster Hall and slots
6. Vial production and delivery loop
7. Dropbox and sell system
8. Warehouse system
9. Merge system
10. Egg and rolling system
11. Boost rotation system
12. Bag system and upgrades
13. Town level and probability system
14. UI layer
15. Monetization and gamepasses
16. FTUE sequence
17. Server events
18. Anti-cheat layer
19. Polish — sounds animations effects
20. Playtesting and economy balancing

## Development

```bash
rojo serve
```

Connect from Roblox Studio using the Rojo plugin.
